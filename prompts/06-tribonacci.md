# Prompt: Tribonacci (ข้อสอบข้อ 6)

## บทบาท

คุณคือ Senior TypeScript Developer 

## โจทย์ (ตามต้นฉบับ)

ให้เขียน function หา Tribonacci หลายคนอาจจะคุ้นเคยกับ Fibonacci อยู่แล้ว ซึ่ง Fibo จะเป็นการบวกกันของ 2 ตัวข้างหน้า แต่ Tribo จะแตกต่างกันคือเป็นการบวกกันของ 3 ตัวข้างหน้า

ตัวอย่าง Tribonacci
- `[1, 1, 1, 3, 5, 9]`
- `[2, 3, 1, 6, 9, 16]`

ให้เขียน function ที่รับค่าเป็น 2 ค่า
1. ค่าแรกเป็น `[Int]` คือค่าเริ่มต้น มีจำนวนตั้งแต่ 0 ถึง 3 ตัว เช่น `[]`, `[5, 2, 0]`, `[1]`, `[3, 4, 1]`
2. ค่าที่สองเป็น non-negative int บอกจำนวนสมาชิกที่ต้องการ **โดยนับรวมค่าเริ่มต้นด้วย** เช่น 0, 5, 3

ตัวอย่างผลลัพธ์
```
f([1, 3, 5], 5)    => [1, 3, 5, 9, 17]
f([2, 2, 2], 3)    => [2, 2, 2]
f([10, 10, 10], 4) => [10, 10, 10, 30]
```

> หมายเหตุ: ตัวอย่างชุดที่ 2 ในโจทย์คำนวณผิด (3 + 1 + 6 = 10 ไม่ใช่ 9) ให้ยึดกฎ "บวก 3 ตัวข้างหน้า" เป็นหลัก ผลที่ถูกคือ `[2, 3, 1, 6, 10, 17]` และให้บอกผมด้วยถ้าเจอจุดผิดอื่นในโจทย์

## กติกาที่ต้องตีความ (อย่าเดาเงียบ ๆ)

โจทย์ไม่ได้บอกพฤติกรรมของเคสเหล่านี้ไว้ ให้คุณ **เลือกพฤติกรรมที่สมเหตุสมผลที่สุด แล้วเขียนบอกผมชัด ๆ ว่าตีความแบบไหนและเพราะอะไร** ก่อนเขียนโค้ด

1. ค่าเริ่มต้นมีน้อยกว่า 3 ตัว (`[]`, `[1]`, `[1, 2]`) ตัวถัดไปคำนวณยังไง
2. ค่าเริ่มต้นเป็น `[]` แต่ขอจำนวนมากกว่า 0 ควรได้อะไร
3. จำนวนที่ขอน้อยกว่าจำนวนค่าเริ่มต้น เช่น `f([1, 3, 5], 2)`
4. จำนวนที่ขอเป็น 0

## ข้อกำหนดของโค้ด


- ห้ามแก้ array ค่าเริ่มต้นที่ส่งเข้ามา (no mutation)
- ทำงานเป็น O(n) ไม่ใช้ recursion

## สิ่งที่ต้องส่งกลับมา (ตามลำดับนี้)

1. **การตีความ** ของเคสกำกวมทั้ง 4 ข้อด้านบน (ข้อละ 1 บรรทัด)
2. **โค้ดคำตอบ** 
3. **โค้ดทดสอบ** ที่ครอบคลุม:
   - ตัวอย่างทั้ง 3 ข้อจากโจทย์
   - ตัวอย่าง Tribonacci ทั้ง 2 ชุด
   - ค่าเริ่มต้น 0, 1 และ 3 ตัว
   - จำนวนที่ขอเป็น 0 และน้อยกว่าจำนวนค่าเริ่มต้น
   - ตรวจว่า array ค่าเริ่มต้นไม่ถูกแก้
4. **ผลการรันเทสจริง**
