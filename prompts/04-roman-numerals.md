# Prompt: Modern Roman Numerals (ข้อสอบข้อ 4)

## บทบาท

คุณคือ Senior TypeScript Developer

## โจทย์ (ตามต้นฉบับ)

Modern Roman Numerals เป็นรูปแบบการนับเลขแบบหนึ่ง เริ่มต้นที่ 1 และนับจากทางซ้ายสุด ไม่มีเลข 0 และมีรูปแบบ CM => 900 (อันนี้เป็นกฎพื้นฐานของเลขโรมัน เช่น IV = 4, IX = 9) ใช้สัญลักษณ์ตามนี้

| Symbol | Value |
|---|---|
| I | 1 |
| V | 5 |
| X | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| M | 1,000 |

ตัวอย่างการแปลง
```
1989 => MCMLXXXIX
2000 => MM
68   => LXVIII
109  => CIX
```

ให้เขียน 2 function
1. รับ Int แล้วแปลงเป็น String รูปแบบ Roman Numerals
2. รับ String รูปแบบ Roman Numerals แล้วแปลงเป็น Int

## กติกาที่ต้องตีความ (อย่าเดาเงียบ ๆ)

โจทย์ไม่ได้บอกพฤติกรรมของเคสเหล่านี้ไว้ ให้คุณ **เลือกพฤติกรรมที่สมเหตุสมผลที่สุด แล้วเขียนบอกผมชัด ๆ ว่าตีความแบบไหนและเพราะอะไร** ก่อนเขียนโค้ด

1. ช่วงตัวเลขที่รองรับ (เลขโรมันมาตรฐานเขียนได้ถึงเท่าไหร่)
2. Input ที่แปลงไม่ได้ เช่น `0`, ติดลบ, ทศนิยม, เกินช่วง ควรทำยังไง (throw error หรือ return ค่าพิเศษ)
3. String ที่มีตัวอักษรที่ไม่ใช่เลขโรมัน เช่น `"ABC"` หรือ string ว่าง
4. String ที่ใช้ตัวอักษรถูกแต่เขียนผิดรูปแบบ เช่น `"IIII"`, `"VV"`, `"IC"` ควรยอมรับหรือไม่
5. ตัวพิมพ์เล็ก เช่น `"mcmlxxxix"` ควรรับได้หรือไม่

## ข้อกำหนดของโค้ด


- ตารางค่าสัญลักษณ์ประกาศไว้ที่เดียว ไม่ hard-code ซ้ำหลายที่
- Error message ต้องบอกได้ว่า input ตัวไหนผิด

## สิ่งที่ต้องส่งกลับมา (ตามลำดับนี้)

1. **การตีความ** ของเคสกำกวมทั้ง 5 ข้อด้านบน (ข้อละ 1 บรรทัด)
2. **โค้ดคำตอบ** ทั้ง 2 function 
3. **โค้ดทดสอบ** ที่ครอบคลุม:
   - ตัวอย่างทั้ง 4 ข้อจากโจทย์ ทั้งขาไปและขากลับ
   - กลุ่มเลขลบ (subtractive) ทั้ง 6 แบบ: 4, 9, 40, 90, 400, 900
   - ค่าต่ำสุดและสูงสุดที่รองรับ
   - แปลงไปแล้วแปลงกลับต้องได้เลขเดิม ทุกตัวในช่วงที่รองรับ (round-trip)
   - input ผิดทุกแบบจากหัวข้อ "กติกาที่ต้องตีความ"
4. **ผลการรันเทสจริง**
